# Szalézi AKK – PHP verzió

Futtatás fejlesztéshez (PHP 8.0+):

    php -S localhost:8000

Szerkezet:
- `index.php`, `bemutatkozas.php`, `szakmaink.php` – oldalak
- `includes/header.php`, `footer.php` – közös keret
- `includes/nav.php` – menü (egy helyen szerkeszthető)
- `includes/adatok.php` – képzések adatai
- `includes/functions.php` – segédfüggvények (`e()`, szűrés)
- `assets/style.css` – stílus
